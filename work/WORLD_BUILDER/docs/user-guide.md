# WORLD BUILDER 사용자 매뉴얼

## 1. 시작하기

처음 열면 샘플 프로젝트 **SERIM_CITY**(섬 4개, 도로, 다리 3개, 건물·시설물)가 열립니다. 이전에 작업하다 저장하지 않고 닫았다면 **복구 대화상자**가 먼저 뜹니다.

화면 구성:

| 위치 | 내용 |
|---|---|
| 상단 | 로고 · 프로젝트 이름(클릭 = 프로젝트 설정) · 저장 상태 · 메뉴(File/Edit/View/Terrain/Objects/Window/Help) · Undo/Redo · Save · Export · Settings |
| 왼쪽 | 도구 10개 |
| 캔버스 위 | 현재 도구의 옵션 바 |
| 중앙 | 지도 캔버스 |
| 아래 | Asset Library |
| 오른쪽 | Inspector(속성) · Layers / Hierarchy 탭 |
| 맨 아래 | 도움말 힌트 · 스냅 · 선택 개수 · 렌더 중 객체 수 · 커서 월드 좌표 · 줌 · FPS |

## 2. 화면 이동

| 동작 | 방법 |
|---|---|
| 확대/축소 | 마우스 휠 (커서 위치 기준) · `+` / `-` |
| 화면 이동 | 가운데 버튼 드래그 · `Space` + 드래그 · Pan 도구(2/H) · `Shift` + 휠(가로) |
| 전체 보기 | `Home` |
| 선택 객체로 이동 | `F` 또는 Hierarchy에서 더블클릭 |
| 100% | `Ctrl+1` 또는 상태바의 줌 % 클릭 |

## 3. 도구

| 키 | 도구 | 하는 일 |
|---|---|---|
| 1 / V | Select | 선택, 이동, 크기, 회전, 점 편집 |
| 2 / H | Pan | 화면 이동 |
| 3 / I | Island | 섬 만들기 (Polygon / Freehand) |
| 4 / C | Coastline | 섬 외곽 꼭짓점 편집, 해안선 유형 칠하기 |
| 5 / T | Terrain Brush | 섬 내부 지형 칠하기 / 지우기 / 채우기 |
| 6 / R | Road | 도로 만들기 |
| 7 / B | Bridge | 섬과 섬을 잇는 다리 |
| 8 / U | Building | 선택한 건물 에셋 배치 |
| 9 / A | Area | 구역(사건 현장, 출입 제한 등) 다각형 |
| 0 / E | Asset | 선택한 에셋(나무·차량·시설물 등) 배치 |

### 3.1 Select
- 클릭: 선택 · `Shift`+클릭: 추가/제외 · 빈 곳 드래그 또는 **`Ctrl`+드래그**: 박스 선택(박스 안에 완전히 들어온 객체만, 섬 위에서도 가능)
- 드래그: 이동 (`Shift` = 가로/세로 고정, Snap to Grid 켜면 격자에 맞춤)
- 흰 네모 핸들: 크기 조절 (`Shift` = 비율 유지) · 위쪽 파란 원: 회전 (`Shift` = 15° 단위)
- 방향키: 1px 이동 (`Shift` = 10px)
- 도로·다리·영역을 하나만 선택하면 점이 표시됩니다: 점 드래그로 이동, 선 위 더블클릭으로 점 추가, `Alt`+클릭(또는 점 클릭 후 `Delete`)으로 삭제. 베지어 도로는 노란 핸들로 곡선을 조절합니다.
- 섬을 더블클릭하면 Coastline 도구로 바뀝니다.

### 3.2 Island
- **Polygon**: 클릭으로 꼭짓점 추가 → 더블클릭, `Enter`, 또는 첫 점 클릭으로 완성. 오른쪽 클릭/`Backspace` = 마지막 점 취소, `Esc` = 취소.
- **Freehand**: 드래그로 외곽선을 그리고 놓으면 완성. 옵션 바의 Simplify 값만큼 꼭짓점이 자동 단순화됩니다.
- 옵션: 섬 유형, 기본 텍스처, 해안선 유형.
- 섬 복제는 선택 후 `Ctrl+D`. 이동·크기·회전은 Select 도구 또는 Inspector.

### 3.3 Coastline
1. 섬을 클릭해 대상 지정.
2. **Edit Vertices**: 꼭짓점 드래그, 가장자리 더블클릭으로 추가, `Alt`+클릭 또는 `Delete` 로 삭제(최소 3개).
3. **Paint Edges**: Paint type(Sand, Rock, Cliff, Concrete, Harbor, Seawall, Default)을 고르고 가장자리를 클릭하거나 드래그해 칠합니다. 섬 전체 기본 유형과 폭은 Inspector ▸ Coastline 에서 바꿉니다.

내부 지형과 해안선은 따로 저장되며, 꼭짓점을 바꿔도 칠해 둔 지형은 유지됩니다.

### 3.4 Terrain Brush
- **Brush**: 섬 안에서 드래그. Material(Grass, Sand, Rock, Concrete, Soil, Water), Size(`[` `]`), Strength(가장자리로 갈수록 옅게 칠해짐).
- **Eraser**: 섬 기본 텍스처로 되돌림.
- **Fill**: 클릭한 곳과 같은 재질로 이어진 영역 전체를 채움.
- 섬 밖에는 칠해지지 않습니다(다각형 마스크). 한 번의 드래그 = Undo 한 단계.

### 3.5 Road
- 클릭으로 점 추가 → 더블클릭 또는 `Enter` 로 완성. 오른쪽 클릭 = 마지막 점 취소.
- 옵션: 도로 유형(폭·차선 기본값이 따라 바뀜), Straight / Smooth / Bezier, 폭, 차선, 방향.
- 다른 도로의 **점** 근처를 클릭하면 초록 원이 나타나며 교차로로 연결됩니다. **선** 위를 클릭하면 상대 도로에 점이 추가되며 연결됩니다. 연결된 점은 함께 움직입니다.

### 3.6 Bridge
1. 시작 섬의 해안선을 클릭(초록 원 = 스냅 위치).
2. (선택) 바다 위를 클릭해 굽는 지점 추가.
3. 다른 섬의 해안선을 클릭하면 완성.
4. 폭·유형·차선은 옵션 바에서 미리 고르거나 나중에 Inspector에서 바꿉니다.

다리 끝이 섬 해안선에서 벗어나면(섬을 옮기는 등) 다리에 **주황 점선과 ! 표시**가 생기고 Inspector에 이유가 나옵니다. 끝점을 해안선으로 드래그하거나 Inspector ▸ **Snap ends to coastline** 으로 고칩니다.

### 3.7 Building / Asset
- Asset Library에서 에셋을 클릭하면 알맞은 도구로 바뀌고, 캔버스를 클릭하면 배치됩니다(`R` = 90° 회전).
- 에셋 카드를 캔버스로 **드래그 앤 드롭** 해도 배치됩니다. 카드 더블클릭 = 화면 가운데에 배치.
- 배치된 위치의 섬이 자동으로 `islandId` 에 기록됩니다.

### 3.8 Area
Polygon/Freehand로 구역을 그립니다. 구역 유형(Zone, Investigation, Restricted, Spawn, Custom)별 색이 다르며 Inspector에서 색·설명을 바꿀 수 있습니다.

## 4. Inspector
- 아무것도 선택하지 않으면 **프로젝트 설정**(이름, 월드 크기, 바다 색, 격자 크기)과 통계.
- 하나를 선택하면 ID, 이름, 유형, 레이어, 표시, 잠금, 위치, 크기, 회전 + 유형별 속성.
- 여러 개를 선택하면 레이어/표시/잠금 일괄 변경, 정렬 6종, 그룹/해제, 복제, 삭제.
- 입력은 즉시 캔버스에 반영되며 잘못된 값(음수 크기, 없는 섬·에셋, 시작=끝 섬인 다리 등)은 빨간 메시지와 함께 적용되지 않습니다.
- 같은 칸을 연속으로 바꾸면 Undo 한 단계로 합쳐집니다.
- 건물 ▸ **Hitbox**: 유형 Rectangle / Polygon / Custom Shape(이미지 불투명 부분 외곽 자동 추출). **Edit hitbox** 를 누르면 빨간 점을 드래그·추가(더블클릭)·삭제(`Alt`+클릭)할 수 있습니다. 히트박스는 건물 로컬 좌표로 저장됩니다.

## 5. Layers & Hierarchy
- 눈 아이콘: 표시/숨김 · 자물쇠: 잠금(캔버스에서 선택·편집 불가) · 슬라이더: 투명도 · 이름 더블클릭: 이름 변경.
- 레이어 행을 클릭한 뒤 툴바에서 위/아래 이동, **선택 객체를 이 레이어로 이동**, 삭제(안의 객체는 이웃 레이어로 옮겨짐).
- **Hierarchy**: 섬 아래에 그 섬의 도로·건물·시설·구역이 계층으로 표시됩니다. 다리는 Bridges, 섬 밖 객체는 "Not on an island". 필터 검색, 클릭 = 선택, 더블클릭 = 이동.

## 6. Asset Manager
1. Asset Library ▸ **Import Asset**
2. 이미지 선택(PNG, JPG, WebP, SVG, 15 MB 이하)
3. 이름, 카테고리, 기본 크기, Anchor(Center / Top Left / Bottom Center / Custom) 입력
4. 미리보기에서 앵커 위치(주황 십자) 확인 → **Save asset**

- 카드에 마우스를 올리면 편집(연필)·삭제(휴지통) 버튼이 나옵니다.
- 사용 중인 에셋은 삭제할 수 없으며, 어떤 객체가 쓰고 있는지 목록을 보여 줍니다.
- 가져온 이미지는 브라우저(IndexedDB)에 저장되고, ZIP으로 내보내면 `assets/` 폴더에 들어갑니다.

## 7. 저장과 불러오기

| 메뉴 | 동작 |
|---|---|
| File ▸ New Project | 빈 프로젝트 (`Ctrl+N`) |
| File ▸ Open… | `.json` 또는 `.zip` 열기 (`Ctrl+O`) |
| File ▸ Save | 같은 파일에 덮어쓰기(Chrome/Edge). 처음이면 Save As (`Ctrl+S`) |
| File ▸ Save As… | 새 파일로 저장 — 파일 이름이 `.zip` 이면 ZIP 패키지로 저장 (`Ctrl+Shift+S`) |
| Export ▸ JSON | `.world.json` 다운로드 |
| Export ▸ ZIP | 프로젝트 + 에셋 이미지 + 썸네일 + metadata 패키지 다운로드 |
| File ▸ Import ZIP Package… | ZIP 열기(에셋 이미지 함께 복원) |
| File ▸ Recover Autosave… | 브라우저에 자동 저장된 최신 상태 불러오기 |

- **자동 저장**: 변경 후 2초(설정 가능)마다 브라우저 IndexedDB에 저장됩니다. 새로고침·브라우저 종료·충돌 후 다시 열면 복구를 제안합니다.
- 저장하지 않은 변경이 있으면 상단 상태가 주황색 **Unsaved** 로 표시되고, 창을 닫을 때 브라우저가 경고합니다.
- **JSON vs ZIP**: JSON에는 이미지가 들어가지 않습니다. 직접 가져온 에셋이 있다면 다른 컴퓨터로 옮길 때 **ZIP**을 쓰세요. JSON만 다른 환경에서 열면 Missing Asset 경고가 뜨고 해당 객체는 빨간 X로 보입니다.
- 손상된 파일, 형식이 틀린 값, 중복 ID가 있는 파일은 열리지 않고 이유가 표시됩니다.

## 8. 설정 (톱니바퀴)
격자 표시 · 격자 스냅 · 객체 스냅(도로/해안선) · 객체 외곽선 표시 · 섬 이름 표시 · 자동 저장 켜기/지연 시간 · Undo 보관 단계 수.

## 9. 단축키 요약

| 단축키 | 동작 |
|---|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` (`Ctrl+Y`) | Undo / Redo |
| `Ctrl+S` / `Ctrl+Shift+S` | Save / Save As |
| `Ctrl+D` / `Delete` | 복제 / 삭제 |
| `Ctrl+A` / `Esc` | 전체 선택 / 취소·선택 해제 |
| `Ctrl+G` / `Ctrl+Shift+G` | 그룹 / 그룹 해제 |
| `G` / `Shift+G` / `O` | 격자 / 격자 스냅 / 외곽선 표시 |

## 10. 성능 테스트
`Help ▸ Performance Test (5,000 objects)` 는 현재 프로젝트를 5,000개 이상 객체가 있는 테스트 월드로 바꾸고 4초 동안 화면을 움직이며 FPS를 잽니다. (저장하지 않은 작업이 있으면 먼저 확인합니다.)

## 11. 아직 없는 기능
PHASE 4(인물, 이동 경로, 건물 출입 기록, 사건, 증거, 시간별 경로 재생)는 구현되지 않았습니다. Characters / Routes / Investigation 레이어와 JSON의 `routes` 배열은 이를 위해 비워 둔 자리입니다.
